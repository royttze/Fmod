## 🚀 Key Features

- **💖 Universal Heroine & Character Studio:** Real-time entity discovery with live affection, obedience, and romance state sliders.
- **🖥️ Transparent In-Game HUD Overlay (`[INSERT]` / `[F11]`):** Zero-latency floating cheat companion directly over the running game.
- **🎒 Universal Inventory & Party Spawner:** Queries game databases directly to extract all items, weapons, armor, and partner actors with instant `+99` injection.
- **🗺️ World, Scene & Combat Matrix:** Speedhacks (0.5x to 10x), No-Clip mode, Zero Encounters, 1-Hit Kills, Map Teleporter, and Cutscene Replayers.
- **💾 Save Time Machine & Snapshot Vault:** Zero-corruption timestamped save snapshots for Ren'Py (`.save`), RPG Maker (`.rpgsave`), and Unity PlayerPrefs.
- **🔓 100% CG Gallery & Scene Unlocks:** Instantly unlocks all scene replays, animations, and art galleries.
- **🌐 Neural Localization Studio:** NLP-guided real-time machine translation with formatting tag protection.
- **🤫 Stealth Privacy Mode (`[F10]`):** Instant one-key toggle that disguises the interface into a mock VS Code programming window.
- **⚡ 2-Second Serverless Hot-Patcher:** Built-in auto-updater delivering instant updates from GitHub Releases.
